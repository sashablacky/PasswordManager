# Версия 1.2: безопасность хранения

Закрывает оставшиеся пункты проверки безопасности (`security-review/risks.md`) и ошибки, найденные при сверке версии 1.1.

## Что изменилось для пользователя

- **Новый формат хранилища.** Старое хранилище переводится в него автоматически при первом входе, тем же мастер-паролем. Если какую-то запись не удаётся расшифровать, перевод не выполняется, хранилище продолжает работать по-старому, а в строке состояния появляется предупреждение. Попытка повторяется при следующем входе.
- **Новые правила мастер-пароля** (только для нового аккаунта и смены пароля, старый пароль продолжает работать): от 12 символов и минимум три вида символов (заглавные, строчные, цифры, знаки) или фраза от 16 символов любых. Пароли на основе `password`, `qwerty`, `123456` и похожих не принимаются. Обязательного спецсимвола больше нет.
- **Экспорт в CSV** предупреждает, что файл не зашифрован, и спрашивает мастер-пароль.
- **Импорт CSV** пропускает плохие строки и сообщает, какие и почему (раньше первая плохая строка обрывала импорт посередине). Понимает CSV из Excel (с BOM). Без названия запись получает его из URL или логина.
- **Восстановление из копии** сначала спрашивает мастер-пароль этой копии и проверяет его, затем сохраняет текущее хранилище рядом как `password_vault_before_restore_<дата>.db` и только потом заменяет его.
- **Блокировка хранилища** сразу очищает скопированный пароль из буфера обмена.
- **Логин в записи необязателен** (PIN-коды, Wi-Fi). Нужно хотя бы название, URL или логин.
- Главное окно и окно проверки утечек помещаются на экран 1366×768.
- Проверка утечек больше не выдумывает источники утечки по словам в пароле (например, «fb» → Facebook): HIBP сообщает только число вхождений.

## Формат хранилища 2 и миграция

- Формат 1 (версии до 1.1 включительно): ключ = Argon2(пароль), проверочное значение = SHA-256(ключ), без связанных данных.
- Формат 2: master = Argon2id(пароль, соль, сохранённые параметры); ключ = HKDF(master, «encryption key»); проверочное значение = HKDF(master, «password verifier»); у каждого шифртекста свои связанные данные.
- Перевод выполняется при входе в одной транзакции: все поля всех записей и зашифрованные результаты проверки утечек перешифровываются новым ключом с новой солью, затем записываются новые параметры. При любой ошибке транзакция откатывается. Смена мастер-пароля использует тот же код.
- Схема базы (новые столбцы, очистка открытых данных) обновляется при запуске программы, ещё до входа. Проверено на копии старой `password_vault.db`: столбцы добавлены, 13 записей журнала очищены, названий в файле не осталось, `integrity_check` = ok.

# Версия 1.1: исправления

Номера соответствуют списку ошибок `bugs/bugs.md`. Сюда же влит патч безопасности (`security-review/security-fixes.patch`).

## Что изменилось для пользователя

- **Lock Vault и автоблокировка работают.** Кнопка возвращает к окну входа и стирает ключ из памяти. После 5 минут бездействия хранилище блокируется, а не закрывается (было 30 секунд и закрытие программы). Время задаётся константой `AUTO_LOCK_MINUTES` в `src/main.py`.
- **У записи есть поле «Title».** Название хранится зашифрованным. Если его не заполнить, берётся из URL, а без URL используется логин. Старые записи без названия по-прежнему получают его из URL.
- **База хранится в папке пользователя:** `%APPDATA%\SecureVault\password_vault.db` на Windows, `~/.local/share/SecureVault` на Linux. При первом запуске существующая база из папки программы или текущей папки **копируется** туда, старый файл остаётся на месте. Путь можно переопределить переменной окружения `PASSWORD_VAULT_DB`.
- **Журнал ошибок** пишется в `error.log` в той же папке (уровень WARNING). Необработанная ошибка теперь показывается в окне, а не теряется молча.
- **Кнопка «Reset Vault and Create New Account»** на экране входа действительно пересоздаёт хранилище (раньше предупреждала об удалении и ничего не делала). Перед удалением рядом сохраняется копия `password_vault_before_reset_<дата>.db`.
- **Окна** входа, добавления записи и генератора помещаются на экран 1366×768. Если места не хватает, форма прокручивается, а кнопки OK/Cancel/Close всегда видны.
- **Фильтр All/Strong/Medium/Weak работает.** Поиск учитывает выбранный вид, категорию и фильтр и больше не сбрасывается сам собой (убрано автообновление каждые 30 секунд, таблица обновляется после каждого изменения).
- **Проверка утечек:** без интернета пароль помечается «❔ NOT CHECKED» вместо «✅ CLEAN». При ошибке больше не появляется «completed successfully». После проверки в таблице остаются все результаты. Кнопка «Change» открывает окно редактирования записи, где можно сгенерировать и сохранить новый пароль.
- **Восстановление из копии** проверяет, что файл действительно хранилище, и затем просит войти паролем от этой копии (раньше показывало пустой список, если пароль копии другой).
- **Буфер обмена** очищается через 30 секунд и при выходе во всех окнах (из патча безопасности).
