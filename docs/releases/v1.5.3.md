## Что нового в 1.5.3

- **Если программа не может запуститься, она это показывает.** Раньше при ошибке на старте собранная программа для Mac молча закрывалась. Теперь появляется окно «Password Manager could not start» с причиной, а подробности записываются в журнал `error.log` (как его найти — в инструкции, раздел 5).
- **В окне установки есть файл «Как открыть в первый раз»** с пошаговой инструкцией крупным шрифтом. На macOS 15 после «Всё равно открыть» в Настройках программу нужно **запустить ещё раз** и подтвердить во втором окне — это нормально.
- **Программа для Mac подходит для macOS 11 и новее.** Раньше часть библиотек в сборке для Intel требовала macOS 14–15; сборка теперь проверяет это автоматически.
- Расширение для Safari: программа обращается к папкам Safari, только если установлено приложение «SecureVault for Safari».
