## Что нового в 1.5.5

- **Версия для Windows.** В релизе теперь есть установщик `…-Windows-Setup.exe` (ставится без прав администратора, ярлык в меню «Пуск», удаляется через «Параметры → Приложения» и не трогает пароли) и `…-Windows-Portable.zip` без установки. Инструкция: [docs/windows-install.md](https://github.com/sashablacky/PasswordManager/blob/main/docs/windows-install.md).
- Если программа не может запуститься, на Windows тоже появляется окно с причиной, а подробности записываются в `error.log`.
- Для Mac всё как в 1.5.4: окно установки со стрелкой и памятка «Как открыть в первый раз».
