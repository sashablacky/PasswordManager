## Что нового в 1.6.0 (Windows)

- **Расширение для Firefox.** В релизе есть `…-Firefox.xpi`, подписанное Mozilla: нажмите на файл в Firefox и подтвердите установку. Расширение заполняет логины и пароли из программы, предлагает сохранить новый пароль после входа на сайт и придумывает надёжные пароли. Подключение: значок SecureVault → «Подключить», затем **Allow** в программе.
- **Установщик сам связывает программу с Firefox**, Python не нужен. При удалении программы связь убирается.
- Подключение браузера больше не зависает на «Подключаюсь к SecureVault…».
- Пока расширение включено, встроенный менеджер паролей Firefox выключен, чтобы не предлагать сохранить те же пароли второй раз. Сохранённые в Firefox пароли остаются. При отключении расширения настройка Firefox возвращается.
- Версия для Mac остаётся 1.5.5: [Password Manager 1.5.5 для Mac](https://github.com/sashablacky/PasswordManager/releases/tag/v1.5.5).
