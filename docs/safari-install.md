# SecureVault в Safari: установка на Mac

Инструкция для того, кто настраивает Mac. Нужно один раз собрать расширение в Xcode прямо на этом Mac. Это занимает около часа, большая часть уходит на скачивание Xcode. Понадобится Терминал, но только для одной команды.

## Что нужно заранее

- **Программа Password Manager уже стоит** на этом Mac и в ней создан мастер-пароль (см. `docs/macos-install.md`).
- **macOS 13.5 или новее**: меню  → «Об этом Mac».
- **Около 20 ГБ свободного места** для Xcode.
- **Apple ID**: подойдёт любой, бесплатный, платный аккаунт разработчика не нужен. Можно взять свой.

## 1. Установить Xcode

1. Откройте App Store, найдите **Xcode** и нажмите «Загрузить». Он бесплатный и большой, скачивание может занять долго.
2. Запустите Xcode один раз. Согласитесь с лицензией и дождитесь, пока он поставит дополнительные компоненты. Если он спросит про платформы (iOS, watchOS и другие), их можно не ставить, нужен только macOS.
3. Xcode → **Settings…** → вкладка **Accounts** → «+» внизу → **Apple ID** → войдите.

## 2. Скачать исходники

1. Откройте https://github.com/sashablacky/PasswordManager, нажмите зелёную кнопку **Code** → **Download ZIP**.
2. Дважды щёлкните по скачанному архиву. Появится папка `PasswordManager-main`. Перетащите её в «Документы».

## 3. Собрать проект

1. Откройте **Терминал** (Программы → Утилиты → Терминал).
2. Вставьте и нажмите Return:
   ```
   cd ~/Documents/PasswordManager-main && sh browser-extension/safari/build_safari.sh
   ```
   В конце скрипт напишет строку `Project: …/SecureVault for Safari.xcodeproj`.
3. Откройте этот проект: в Finder перейдите в `Документы/PasswordManager-main/browser-extension/safari/build` и дважды щёлкните по файлу `.xcodeproj`.

## 4. Подписать и запустить

1. В Xcode слева нажмите на самый верхний синий значок проекта. В середине появится список **Targets**, в нём две строки: `SecureVault for Safari` и `SecureVault for Safari Extension`.
2. Для **каждой** из двух строк: вкладка **Signing & Capabilities** → поле **Team** → выберите своё имя с пометкой «(Personal Team)». В разделе **App Groups** у расширения должна стоять галочка у группы, которая заканчивается на `securevault.bridge`.
3. Нажмите ▶ (Run) вверху слева. Появится маленькое окно «SecureVault for Safari». Его можно закрыть.
4. Чтобы расширение не пропало, положите приложение в «Программы»: в Xcode меню **Product → Show Build Folder in Finder** → `Products` → `Debug` → перетащите **SecureVault for Safari** в «Программы». Затем один раз откройте его оттуда двойным щелчком.

## 5. Включить расширение в Safari

1. Safari → **Настройки…** → **Расширения**. Поставьте галочку у **SecureVault**.
2. Там же нажмите «Изменить веб-сайты» (или «Разрешения») и для «Другие веб-сайты» выберите **Разрешить**. Без этого расширение не увидит поля входа на сайтах.
3. На панели Safari появится значок замка. Если его нет: меню «Вид» → «Настроить панель инструментов» и перетащите значок на панель.

Если SecureVault не появился в списке расширений: Safari → Настройки → «Дополнения» → включите «Показывать функции для веб-разработчиков», затем меню «Разработка» → **Разрешить неподписанные расширения**. Этот флажок сбрасывается после каждого перезапуска Safari, поэтому это только запасной вариант. Скорее всего, что-то не так с подписью на шаге 4.

## 6. Подключить Safari к программе

1. Запустите Password Manager и введите мастер-пароль.
2. В Safari нажмите на значок замка → **Подключить**. Откроется вкладка с шестизначным кодом.
3. Перейдите в Password Manager. Появится окно «Safari wants to use passwords from this vault» с тем же кодом. Если коды совпадают, нажмите **Allow**.
4. macOS 15 может спросить, разрешить ли Password Manager доступ к данным других приложений. Нажмите **Разрешить**: через эту папку программа разговаривает с расширением.
5. Вкладка в Safari напишет «Готово».

Проверить: откройте сайт, пароль от которого есть в программе, нажмите на значок замка. В окне появится этот вход, щелчок по нему заполнит логин и пароль.

## Как этим пользоваться каждый день

- **Сначала откройте Password Manager и введите мастер-пароль.** Пока программа закрыта или на замке, расширение пишет «SecureVault заблокирован» и ничего не заполняет.
- **Войти на сайт:** откройте страницу входа, нажмите на значок замка в Safari и выберите нужный вход. Или нажмите ⌘⇧L: заполнится первый вход для этого сайта.
- **Новый пароль:** после входа на сайт с паролем, которого нет в программе, справа вверху появится вопрос «Сохранить пароль в SecureVault?». Нажмите **Сохранить**. Если пароль от сайта поменялся, будет вопрос «Обновить сохранённый пароль?».
- **Регистрация:** нажмите на значок замка → «Придумать надёжный пароль». Пароль сам встанет в поля, а после регистрации расширение предложит его сохранить.

## Если что-то не работает

- «SecureVault не запущен»: запустите Password Manager.
- «SecureVault не настроен для этого браузера»: приложение SecureVault for Safari не открывалось или удалено. Повторите шаг 4.
- Расширение пропало из Safari через какое-то время. Бесплатная подпись Apple ID ограничена по сроку; проверить на настоящем Mac, насколько, пока не удалось. Откройте проект в Xcode, нажмите ▶ (Run) и снова скопируйте приложение в «Программы», как на шаге 4.
- Отключить браузер: Password Manager → **Settings** → **Browser extension** → **Disconnect all**. Выключить связь с браузером совсем: там же переключатель **Allow browser extension**.
