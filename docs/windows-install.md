# Password Manager на Windows: установка и резервная копия

Программа для Windows 10 и 11 (64-бит).

## 1. Скачать

Откройте https://github.com/sashablacky/PasswordManager/releases/latest и внизу, в разделе **Assets**, нажмите на файл:

| Файл | Когда брать |
|---|---|
| **`PasswordManager-…-Windows-Setup.exe`** | обычно: установщик, ярлык в меню «Пуск» |
| `PasswordManager-…-Windows-Portable.zip` | без установки: распаковать в любую папку (или на флешку) и запускать `Password Manager.exe` |

Входить в GitHub не нужно. Файл окажется в папке «Загрузки».

## 2. Установить

1. Дважды щёлкните по `PasswordManager-…-Windows-Setup.exe`.
2. Программа не подписана платным сертификатом, поэтому Windows может показать синее окно **«Система Windows защитила ваш компьютер»**. Нажмите **«Подробнее»**, затем **«Выполнить в любом случае»**. Браузер (Edge, Chrome) при скачивании тоже может спросить, сохранить ли файл: выберите **«Сохранить»** / **«Всё равно сохранить»**.
3. В установщике нажимайте **«Далее»**. Права администратора не нужны: программа ставится только для вас, в папку `%LOCALAPPDATA%\Programs\Password Manager`. По желанию отметьте «Создать значок на рабочем столе».
4. В конце оставьте галочку **«Запустить Password Manager»** и нажмите **«Завершить»**.

Дальше программа запускается из меню **«Пуск» → Password Manager** (или с рабочего стола).

Если программа показала окно **«Password Manager could not start»**, сфотографируйте его и пришлите Саше: в окне написана причина, подробности записаны в `error.log` (раздел 4).

## 3. Первое знакомство

Программа на английском языке.

1. При первом запуске придумайте **мастер-пароль**: введите его в поле «Master password», нажмите **Create vault** и повторите в окне «Re-enter password». **Восстановить мастер-пароль нельзя**, запишите его на бумаге и храните в надёжном месте.
2. Потом при каждом запуске вводите мастер-пароль и нажимайте **Unlock**.
3. Без дела программа через 5 минут закрывается на замок (время меняется в Settings → Vault → Lock automatically).
4. Скопированный пароль сам стирается из буфера обмена через 30 секунд.

Горячие клавиши: Ctrl+N — новая запись, Ctrl+F — поиск, Ctrl+G — генератор, F5 — обновить, Delete — удалить запись, Ctrl+L — замок, Ctrl+Q — выход.

## 4. Где хранятся пароли

Все пароли — в одном зашифрованном файле **password_vault.db** на этом компьютере, в интернет он не отправляется. Папка: нажмите **Win + R**, вставьте `%APPDATA%\SecureVault` и нажмите **Enter**. Там же `settings.json` (тема) и `error.log` (журнал ошибок). Ничего в этой папке руками не меняйте.

## 5. Резервная копия

Время от времени (например, раз в месяц) делайте копию: в программе слева внизу **Settings** → **Create backup** → сохраните файл `backup_<дата>.db` в облако (OneDrive, Яндекс Диск) или на флешку. Копия зашифрована мастер-паролем.

Вернуть пароли из копии: **Settings** → **Restore from backup** → выбрать файл → ввести мастер-пароль той копии.

## 6. Обновление и удаление

- **Новая версия:** скачайте новый `Setup.exe` с той же страницы и установите поверх, закрыв программу. Пароли сохранятся.
- **Удалить программу:** «Пуск» → «Параметры» → «Приложения» → **Password Manager** → «Удалить». Пароли при этом **не удаляются**: папка `%APPDATA%\SecureVault` остаётся. Чтобы удалить и её, откройте её (раздел 4) и удалите вручную — только если пароли больше не нужны или есть копия.
- **Portable-версию** удаляют вместе с её папкой; пароли так же остаются в `%APPDATA%\SecureVault`.

## 7. Расширение для Firefox

Расширение SecureVault заполняет логины и пароли из программы прямо в Firefox. Установщик `Setup.exe` уже связывает программу с Firefox, отдельно ничего настраивать не нужно (Portable-версия этого не делает). Само расширение пока ставится вручную, как описано в [browser-extension/README.md](../browser-extension/README.md). Затем запустите и разблокируйте программу, нажмите значок SecureVault в Firefox → **«Подключить»** и в программе нажмите **Allow**, если коды совпадают.
